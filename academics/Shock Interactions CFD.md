# Determination of the First Inflation Layer Height

To accurately resolve the near-wall boundary layer, the first inflation layer height was estimated using the $y^+$ approach. Since the wall shear stress is unknown prior to the CFD simulation, empirical correlations based on the Reynolds number were used to obtain an initial estimate. The characteristic length $L$ was chosen as the distance from the inlet to the first compression corner, representing the boundary-layer development length prior to shock interaction.

### Step 1: Calculate Free-Stream Velocity

The inlet velocity was determined from the specified Mach number:

$$U = M\sqrt{\gamma RT}$$

where $M$ is the Mach number, $\gamma$ is the ratio of specific heats, $R$ is the gas constant for air, and $T$ is the inlet temperature.

### Step 2: Calculate Reynolds Number

The Reynolds number was computed as:

$$Re = \frac{\rho UL}{\mu}$$

where $\rho$ is the air density, $U$ is the free-stream velocity, $L$ is the characteristic length, and $\mu$ is the dynamic viscosity of air. The viscosity was evaluated using Sutherland's law.

### Step 3: Estimate Skin-Friction Coefficient

For a turbulent boundary layer, the skin-friction coefficient was estimated using:

$$C_f = 0.058 \cdot Re^{-0.2}$$

### Step 4: Determine Wall Shear Stress

The wall shear stress was then estimated from:

$$\tau_w = C_f \left( \frac{1}{2} \rho U^2 \right)$$

### Step 5: Calculate Friction Velocity

The friction velocity was obtained from:

$$u_{\tau} = \sqrt{\frac{\tau_w}{\rho}}$$

### Step 6: Calculate First Layer Height

For a target wall resolution of $y^+ = 1$, suitable for the SST $k-\omega$ turbulence model, the first inflation layer height was calculated as:

$$\Delta y = \frac{y^+ \mu}{\rho u_{\tau}}$$

where $\Delta y$ is the height of the first cell adjacent to the wall.

### Step 7: Validation Using Fluent

After generating the mesh and running an initial simulation, the wall $y^+$ distribution was evaluated in ANSYS Fluent. The first-layer height was subsequently refined, if necessary, to maintain $y^+$ values close to the target value over the wall surfaces.

# Initial Flow Conditions

The simulation was conducted using compressible flow assumptions to capture the shock structures generated by the compression corners. Air was modeled as an ideal gas with temperature-dependent viscosity evaluated using Sutherland's law.

### Input Parameters

| **Parameter**                          | **Value**        |
| -------------------------------------- | ---------------- |
| **Working Fluid**                      | Air (Ideal Gas)  |
| **Flow Regime**                        | Compressible     |
| **Inlet Mach Number ($M$)**            | 3.0              |
| **Static Pressure ($P$)**              | 101,325 Pa       |
| **Static Temperature ($T$)**           | 300 K            |
| **Ratio of Specific Heats ($\gamma$)** | 1.4              |
| **Gas Constant ($R$)**                 | 287 J/(kg·K)     |
| **Dynamic Viscosity Model**            | Sutherland's Law |

### Derived Flow Properties

The following properties were derived from the initial static conditions:

**1. Density ($\rho$):**

Using the ideal gas law:

$$\rho = \frac{P}{RT} = \frac{101,325}{287 \times 300} \approx 1.177 \, \text{kg/m}^3$$

**2. Speed of Sound ($a$):**

$$a = \sqrt{\gamma RT} = \sqrt{1.4 \times 287 \times 300} \approx 347.2 \, \text{m/s}$$

**3. Flow Velocity ($U$):**

$$U = M \cdot a = 3 \times 347.2 \approx 1,041.6 \, \text{m/s}$$

**4. Dynamic Viscosity ($\mu$):**

Evaluated via Sutherland's law at 300 K:

$$\mu \approx 1.846 \times 10^{-5} \, \text{kg/(m}\cdot\text{s)}$$

### Methodology Summary

The inlet flow conditions corresponded to a Mach 3 supersonic stream with a static pressure of 101,325 Pa and a static temperature of 300 K. These conditions yielded a free-stream density of 1.177 kg/m³ and a velocity of approximately 1,042 m/s. The choice of these parameters ensures the simulation remains consistent with established supersonic wind tunnel test section conditions.
